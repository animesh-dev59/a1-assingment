# 🌸 Fresh Flower Shop Website

An industry-level, responsive, and modern e-commerce storefront for a fresh flower shop. Built with **Semantic HTML5** and **Modern CSS3**, this project focuses on clean layout structure, DRY principles, and dynamic responsive design.

## 📸 Overview

This application serves as an interactive online flower store UI featuring product catalogs, promotional deal showcases, store highlights, and a newsletter subscription system.

### Key Highlights
- 📱 **Mobile-First Responsive Design:** Built using modern **CSS Grid** and **Flexbox** to seamlessly adapt from desktop to mobile screens.
- 🎨 **Typography & Aesthetics:** Clean visual hierarchy utilizing Google Fonts (*Noto Serif* & *Inter*).
- ⚙️ **Clean Code Architecture:** Structured following the **DRY (Don't Repeat Yourself)** principle with scalable CSS helper classes.
- 🛍️ **Interactive Cards & Overlays:** Product grids with responsive layout shifts and image overlay effects.

---

## 🛠️ Tech Stack & Tools

- **HTML5:** Semantic markup (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **CSS3:** Custom Layouts, Flexbox, CSS Grid, Pseudo-elements (`::before`), and Media Queries.
- **Iconography:** Font Awesome 7.x.
- **Fonts:** Google Fonts (*Noto Serif* and *Inter*).
